# Exercise 1: First Missing Positive

Write a function that returns the smallest positive integer not present in a given list.

## Examples

- `{1, 2, 3, 4, 5, 6}` ---------------> `7`
- `{-10, 4, 19, 1, -88, 12}` -------> `2`
- `{97, 65, 70, 71, -88}` -----------> `1`
- `{1, 6, 3, 8, 2, 4}` ---------------> `5`
