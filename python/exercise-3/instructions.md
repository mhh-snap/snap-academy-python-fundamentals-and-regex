# Exercise 3: Path Finder

## Part 1: Greedy Path
Find the path (top to bottom) through a tree of numbers that always chooses the largest option and output its sum.

### Examples (Greedy Path)

```python
# path is highlighted in comments

   3       # 3
  7 4      # 7
 2 4 6     # 4
8 5 4 9    # 5
```
The sum of the Greedy path in this case is `3 + 7 + 4 + 5 = 19`.

## Part 2: Largest Sum Value
Find the path (top to bottom) through a tree of numbers with the largest sum value.

### Examples (Largest Sum Value)

```python
# path is highlighted in comments

   3       # 3
  7 4      # 4
 2 4 6     # 6
8 5 4 9    # 9
```
The largest sum value in this case is `3 + 4 + 6 + 9 = 22`.
