# Exercise 4: Largest Product in a Series

Find the thirteen adjacent digits in the 1000-digit number that have the greatest product.

## Examples
- `123456789` -----> adjacent digits: `89`, product: `72` (2 adjacent digits in 9-digit number)
- `795436579060` -----> adjacent digits: `6579`, product: `1890` (4 adjacent digits in 12-digit number)
