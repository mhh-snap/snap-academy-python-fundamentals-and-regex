# Exercise 2: Caesar Cipher

The text in `input.txt` has been scrambled using a classic Caesar Cipher. Your task is to write a Python script that systematically tests all possible shifts to decode and reveal the original message. Please find a link below to the Caesar Cipher Wikipedia page: [Caesar Cipher](https://en.wikipedia.org/wiki/Caesar_cipher)

**NOTE:** The Input text is entirely **lower case** and contains **NO** new line characters

## Examples

- `hello world` ------> `khoor zruog` (Encoding with a shift of 3)
- `jerg rercpkztj` -----> `snap analytics` (Decoding with a shift of 17)
